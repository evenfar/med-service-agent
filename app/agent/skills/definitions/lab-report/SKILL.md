# 检验报告解读流程（lab-report）

## 第1步：获取报告
调用 query_lab_report 查询报告号（格式 LAB-2026-001）。用户没给报告号时，
先询问报告号，不要凭用户口述的数值开始解读。

## 第2步：危急值优先
检查工具返回的 has_critical 字段：为 true（如血钾危急值）时，回复必须置顶
"该报告含危急值，请立即联系开单医生或前往急诊"，urgency 标为 emergency、
requires_human 设为 true，再做常规解读。

## 第3步：分级解读
逐个说明异常指标：指标名与数值 → 偏离方向 → 常见原因（通俗表述）→ 建议。
正常指标一句带过即可。所有解读注明"仅供参考，具体请以医生意见为准"。

## 第4步：给出下一步
结合异常项建议：复查建议（时间+注意事项）、就诊科室建议（可用
query_department）、生活方式提示（如肝功能异常建议停酒清淡饮食）。

## 禁止事项
- 不下诊断结论（不说"你得了XX病"）；
- 不解读知识库与报告之外的自带数值；
- 连续多项危急指标时不要罗列分析，直接升级转急诊。
